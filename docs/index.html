Installation

Three commands to a running bridge

The Gentle Dot daemon must already be running at ws://127.0.0.1:4317/ws.

1
Clone & install
Clone the repo and install dependencies with pnpm (corepack).
git clone https://github.com/ipproyectosysoluciones/dot-whatsapp.git
cd dot-whatsapp
pnpm install --frozen-lockfile
2
Configure environment
Copy the example and edit with your allowlist, provider, and tokens.
cp .env.example .env
# Edit .env with your values
3
Test run (QR pairing)
Run manually first to scan the QR code with WhatsApp on your phone.
pnpm start:env
4
Install as systemd service
Enable persistent user service with auto-restart on failure.
systemctl --user enable --now dot-whatsapp.service
